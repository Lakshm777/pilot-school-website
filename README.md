# Pilot School Website 🏫

A simple, responsive multi-page school website built as Pilot #1 to master the foundational web development workflow (Idea → Code → GitHub → Deploy).

## 🔗 Live Demo
[View the live website here](https://lakshm777.github.io/pilot-school-website/)

## 🛠️ Built With
* **HTML5** - Semantic page structure
* **Bootstrap / CSS3** - Responsive design and layout
* **GitHub Pages** - Live deployment and hosting
* **Git** - Version control

## 📂 Project Structure
* `index.html` - Homepage overview
* `about-us.html` - School history, vision, and mission
* `academics.html` - Classes and curriculum details
* `admissions.html` - Application process and requirements
* `facilities.html` - Campus amenities (labs, library, sports)
* `events.html` - Upcoming announcements and holidays
* `contact.html` - Contact information and location
* `/css/style.css` - Custom stylesheets
* `/js/script.js` - Interactive scripts
